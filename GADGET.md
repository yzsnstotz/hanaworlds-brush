# Brush public boundary

`compileBuildDocument` / `compileBuildDocumentBytes` return the local BuildDocumentResponse (BUILD/V5, operations/v4). `compileRegionBuild` / `compileRegionBuildBytes` return CompileRegionBuildResponse (region-build/v2, region-operations/v2). `apply(ctx)` provides `hanaworldsBrushV3`, whose BrushV3 service exposes compile, compileBytes, compileRegion, compileRegionBytes, status and protocolHandshake. Root declarations export the complete local request/response and metadata types.

Only voxel-grid/v1 is expanded. Unknown geometryProfile returns CAPABILITY_GAP / GEOMETRY_PROFILE_UNSUPPORTED with mutationState NONE. Strict local validation governs malformed input, digest bindings, world identity and witnesses. MaterialRef and orientation pass through opaque. Per-cell geometry retains inclusive set_box, last writer wins, exact bounds and numeric coordinate order. No world or model access.

Region blocks are canonically clipped along request.partition.edge with local regionChunksOfBox and encodeRegionBlock. All-unspecified chunks are omitted; only request.catalogue.emptyMaterialRef carves. Every emitted chunk includes the local region-block digest of its block. operationDigest binds the entire projection; validateCompiledRegionSet verifies exact equivalence before return.

Contract validators and types are the complete self-owned C-brush/v3 document closure. Package version is read from package.json and is provenance; existing protocol metadata compatibility governs consumption. Canvas owns transactions/history/Undo. Historical preview, tests and tooling are archived outside the repository by brush-migration-cleanup-01 with a per-file manifest and recovery paths (D-18 / Q-71 B1); Git baseline ca57180e0d25c2321510f353bd7fc1b505c82801 retains the original archive. Current tests include public fixture examples, Cordis mock provision, image, BUILD and multi-chunk/tamper cases.
